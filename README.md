## 📋 Описание

DonWeather — это минималистичное погодное приложение с современным темным интерфейсом. Приложение предоставляет актуальную информацию о погоде, включая текущую температуру, прогноз на несколько дней, основные метрики (влажность, ветер, давление) и рекомендации.

## ✨ Функциональность

- 🌡️ **Текущая погода** — отображение температуры и описания условий
- 📍 **Поиск по городу** — введите название города для получения данных
- 📊 **Метрики** — влажность, скорость ветра, атмосферное давление
- 📅 **Прогноз на 3 дня** — детальный прогноз погоды с температурой
- 💡 **Рекомендации** — полезные советы в зависимости от условий
- 🎨 **Минималистичный UI** — темная тема с градиентными акцентами
- 📱 **Адаптивный дизайн** — корректное отображение на всех устройствах
- ⚡ **Состояния загрузки** — индикатор загрузки данных
- 🚨 **Обработка ошибок** — информативные сообщения об ошибках
- 💾 **Сохранение настроек** — автоматическое сохранение выбранного города

## 🚀 Установка и запуск

### Требования

- Node.js версии `^20.19.0` или `>=22.12.0`
- npm или yarn

### Установка зависимостей

```bash
npm install
```

### Режим разработки

Запуск dev-сервера с hot-reload:

```bash
npm run dev
```

Приложение будет доступно на `http://localhost:5173` (или другом порту, который укажет Vite).

### Сборка для production

Создание оптимизированной сборки:

```bash
npm run build
```

Собранные файлы будут находиться в папке `dist/`.

### Предпросмотр production-сборки

Запуск локального сервера для просмотра production-сборки:

```bash
npm run preview
```

### Линтинг и форматирование

Проверка и исправление кода:

```bash
npm run lint
```

Форматирование кода:

```bash
npm run format
```

## ⚙️ Настройка окружения

Для работы с API необходимо создать файл `.env` в корне проекта:

```env
VITE_API_ENDPOINT=https://your-api-endpoint.com
```

**Важно:** Все переменные окружения, используемые в клиентском коде, должны начинаться с префикса `VITE_`.

### Пример `.env` файла

```env
VITE_API_ENDPOINT=http://localhost:8000
```

## 🎨 Дизайн и стилистика

Приложение использует минималистичную темную цветовую схему с градиентными акцентами.

### Дизайн-система

Все стили основаны на CSS-переменных, определенных в `src/assets/main.css`:

- **Цвета:** Темная палитра (#222831, #272e37) с градиентными акцентами
- **Тени:** Три уровня теней для создания глубины
- **Радиусы:** Единая система скруглений (8px, 12px, 16px)
- **Отступы:** Стандартизированная система отступов
- **Шрифты:** Montserrat для единообразия интерфейса

### Особенности UI

- Плавные анимации при наведении (hover-эффекты)
- Градиентные текстовые элементы для акцентов
- Карточный дизайн с тенями и скруглениями
- Адаптивная верстка с flexbox

## 🐳 Docker

Приложение можно запустить в Docker-контейнере:

### Сборка образа

```bash
docker build -t donweather-front .
```

### Запуск контейнера

```bash
docker run -p 80:80 donweather-front
```

Приложение будет доступно на `http://localhost`.

**Примечание:** Docker-образ использует multi-stage build с nginx для production-развертывания.

## 📦 Компоненты

### CityName

Отображает название текущего города с градиентным текстом и анимацией при наведении.

### WeatherDisplay

Главная карточка с текущей температурой и описанием погодных условий.

### WeatherStats

Отображает метрики:
- Влажность (%)
- Скорость ветра (км/ч)
- Атмосферное давление (мбар)

### WeatherForecast

Прогноз погоды на ближайшие дни с минимальной и максимальной температурой.

### CityInput

Поле ввода для поиска погоды в другом городе. Поддерживает поиск по Enter и кнопке.

### WeatherTips

Блок с рекомендациями на основе текущих погодных условий.

### ErrorDisplay

Компонент для отображения ошибок пользователю. Поддерживает:
- Разные типы ошибок (404, сетевые ошибки и т.д.)
- Автоматическое закрытие через 5 секунд
- Адаптивное позиционирование (центр на мобильных, верхний левый угол на десктопе)
- Анимации появления/исчезновения

### LoadingSpinner

Индикатор загрузки с тремя размерами (small, medium, large) и опциональным сообщением. Использует градиентные кольца в стиле приложения.

### DeveloperContacts

Блок с контактами разработчика (Email, Telegram, Max), расположенный в боковой панели.

### CopyrightFooter

Компонент футера с информацией о копирайте и текущем годе.

## 🔌 API

Приложение взаимодействует с бэкенд-API через следующие эндпоинты:

- `POST /weather/register` — получение данных о погоде

Формат запроса:

```json
{
  "q": "Москва",
  "lang": "ru",
  "day": "3"
}
```
