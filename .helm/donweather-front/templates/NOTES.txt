1. DonWeather Front установлен.

2. Проверить статус:
   kubectl get pods -n {{ .Release.Namespace }} -l app.kubernetes.io/instance={{ .Release.Name }}

3. Если HTTPRoute включён, проверьте доступ по hostname из values.yaml:
{{- if .Values.httpRoute.enabled }}
{{- range .Values.httpRoute.hostnames }}
   https://{{ . }}{{ $.Values.httpRoute.pathPrefix }}
{{- end }}
{{- else }}
   HTTPRoute выключен (httpRoute.enabled=false)
{{- end }}

Важно про API:
- Фронт собирается Vite'ом, и `VITE_API_ENDPOINT` подставляется на этапе сборки образа.
- Рекомендуемый вариант для k8s: собирать фронт с `VITE_API_ENDPOINT=""`, а маршрутизацию `/weather/*` делать через Gateway API (отдельным HTTPRoute на backend service).
